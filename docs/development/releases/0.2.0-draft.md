## Activation boundaries

- Enabled: organization setup, branches, memberships and roles, parties, evidence, tasks, obligations, exports; capability `workspace` per entity after independent activation approval.
- Disabled: every financial capability (`general_ledger` onward) returns `FEATURE_NOT_ENABLED`; approval-policy endpoints wait for ledger routing.
- Production composition prerequisites before any live tenant: S3-compatible evidence store adapter and a production scanner adapter qualified (the filesystem store and fixture scanner refuse to start outside local/demo), `FIELD_ENCRYPTION_KEY` from the secret manager, OIDC provider registration for the workspace, and the owner's review of the contract additions listed in `P02-REVIEW.md`.
